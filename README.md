# expense-tracking-tool 簡易記帳工具
這是一個由二人小組開發的 Python 記帳工具。本專案旨在練習軟體工程中的版本控制實作、模組化設計以及 GUI 介面整合。

## 功能
- **完整 CRUD 功能**：支援新增帳目與刪除選定帳目。
- **直觀 GUI 介面**：採用左右切分佈局，左側為數據清單，右側為即時圓餅圖。
- **優化 UI 體驗**：
  - 清單採用 **斑馬條紋 (Zebra Stripes)** 設計，提升閱讀性。
  - 固定式底部輸入欄位，滾動清單時不影響輸入。
  - 獨立年、月、日輸入，方便補記帳目。
- **即時視覺化**：每當資料變動，圓餅圖與統計比例會自動重繪。
